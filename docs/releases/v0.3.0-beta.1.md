# ISSD Native v0.3.0-beta.1

A **beta prerelease** for Windows and Android. This release improves presentation,
controls and exhibition setup while preserving the original match simulation.
The project is still working toward 1.0.

## Changes

- Saved P1–P4 controller profiles, in-game button/axis/trigger remapping,
  adjustable stick/trigger deadzones and P1 keyboard remapping.
- Configurable Android touch positions/sizes and a background/resume pause path.
- Exhibition rematch, mark/restart drill checkpoints and a persistent favorite;
  Original, Classic, Casual and custom presets use existing verified game rules.
- A default-off Original Bug Fixes bundle for verified keeper movement, skill-point,
  goal/restart, scoreboard and name-graphics defects. It does not fix every
  reported original-game issue.
- Graphics/readability controls, Original/Sharp/Enhanced presets, integer scaling,
  sharply drawn overlays, optional ball cues, player labels/markers and radar
  placement/opacity/size.
- Safer widescreen animation and scene transitions, a 504×224 ultrawide view,
  and 16:10/16:9/21:9 penalty scenery with the original goal, players and HUD.
- Original formation/substitution, request cancellation and advancing save/reload
  acceptance with AI off/on. Preserve original auxiliary admission during wider
  rendering so stale poses are not revived after management return.
- Read-only AI tracing with bounded per-actor roster/formation/condition metadata.
- Audited supported features, acceptance records and a future netplay design.
  Netplay is not implemented in this release.

Existing four-player local multiplayer, Continue Campaign, backup recovery,
configuration compatibility checks and cartridge password interoperability remain
available. Optional AI/bug-fix switches start off; matching applied gameplay data
and switches are required when restoring checked saves. Presentation preferences
remain independent of the gameplay save context.

## Downloads and installation

- **Windows:** extract `ISSDNative-v0.3.0-beta.1-windows-x64.zip` into a fresh folder
  and run `ISSDNative.exe`. Keep `SDL2.dll` and `aot_boot_deny.txt` beside it.
- **Android 8.0+:** sideload `ISSDNative-v0.3.0-beta.1-android.apk` or extract it
  from the Android ZIP. arm64-v8a and x86_64 are included. Version code 5 supports
  upgrading the previous build with the same signing key; back up saves before
  changing installations. Uninstalling removes app-local data.
- **Optional mods:** `liga_mx_expansion.zip` and `world_cup_2026.zip` are separate
  downloads. Extract into a selected mods folder; they are not enabled by default.
- **Checksums:** `SHA256SUMS.txt` covers the downloadable packages.

Supply your own supported International Superstar Soccer Deluxe (USA) cartridge
dump. No ROM, personal configuration, saves or acceptance snapshots are included.
Open the overlay with Escape/F1 or Guide/Home / Back+Start. Original team
management uses SELECT and opens at an eligible stoppage.

## Validation and known limitations

- Shared kit overrides now redirect home and away pointers to isolated records.
  Goalkeeper appearance retains the original cartridge's safe hairstyle convention;
  its documentation and tests now match the actual native behavior.
- Checked snapshots retain widened-player animation and pose history so advancing
  widescreen replay resumes deterministically. Older snapshots remain readable.
- Focused checks passed 59 tests; native replay, save/shortcuts, team-change and
  graphics checks passed 27 tests with one optional fixture skipped. Snapshot
  serializer/transactional checks passed after final arithmetic hardening.
- Package checks verify checksums, archive integrity, both Android ABIs and
  absence of ROM/save snapshots. The APK signature verifies and matches the
  v0.2.0-beta.1 certificate for in-place upgrades.

- The original team-change visual pass covers nine stages, 36 viewport runs and
  468 captures at 256/358/398/504 pixels, matching full endpoint WRAM and sampled
  native-center pixels. The shipped name lookup follows the visible replacement.
- Original formation/substitution commits and deterministic advancing save/reload
  pass with AI off/on. Both-team menus, extra-time substitutions, original
  replacement limits and the substituted human-team actor's optional policy
  decision remain unverified.
- Earlier extended penalty acceptance covers actual human and CPU kicks and the
  next turn; completed shootouts, natural full tournaments and every mode/team
  combination are not certified.
- Physical four-controller, Android lifecycle/touch and display acceptance still
  need device testing. Optional AI tuning needs gameplay balance testing.
- Windows, Linux and Android builds are checked. Downloaded binary packages target
  Windows and Android; SteamOS/macOS packages are not part of this release.
- Android retains the existing debug signing configuration for sideload testing.

See the bundled supported-feature and acceptance guides for precise evidence and
remaining limitations.
