# ISSD Native v0.7.0-beta.1

Cartridge packs beta for Windows x64, Linux x64, Steam Deck (AppImage) and
Android 8.0+. A mod pack can now carry a complete ROM hack - a full cartridge
image, or an IPS patch applied to the retail USA dump you supply - so a hack
plays as a mod while the cartridge stays yours. Supply your own supported
retail cartridge dump. ROMs, personal configuration and saves are not included.

## Changes

- Cartridge packs: a mod can substitute the whole 2 MB cartridge with a full
  image or an IPS patch applied to the user's verified retail ROM. The patch
  holds only the differences and contains no ROM content, so it is the shape to
  share. Regular packs still layer on top. The topmost enabled cartridge pack
  wins; if it cannot be used the retail cartridge plays, and the console and
  the mods page say which pack and why. Switching one takes effect on
  SAVE & RESTART.
- With a cartridge pack active the engine runs the normalized, headerless
  image, so current-build saves are scoped to it. Kit palette tails, stadium
  expansion sites, the added-team gate and its roster run, the bonus-team group
  count and the tone-1 free run are guarded against a changed cartridge and
  refuse with a warning when the bytes are not the retail ones; every other
  regular-pack write still lands at its retail offset.
- Add `tools/convert_rom_hack.py`, which turns a hack image or an existing IPS
  into a cartridge pack and writes a compatibility `REPORT.md` classifying every
  changed region as honored data, interpreted code or not guaranteed.
- Refuse added-team roster writes into cartridge free space that a cartridge
  pack occupies, with a warning, instead of overwriting the hack's data.
- Validate cartridge pack shape, asset paths and `sha256` in
  `tools/validate_mod.py`.
- Add two skin and hair tones per team for roster packs, chosen per player;
  let Mod Studio select the tone and describe the appearance byte, and make the
  validator reject malformed `skin_tones`.
- Retains widescreen, tactical cameras, touch controls, campaign recovery,
  replay fixes, independent stadiums, the retro broadcast launcher and Mod
  Studio from earlier betas.

## Downloads and installation

- **Windows:** extract the Windows ZIP and run `ISSDNative.exe` with `SDL2.dll`
  and `aot_boot_deny.txt` alongside it. Includes the standalone Mod Studio editor.
- **Linux:** extract the Linux tar.gz and run `./ISSDNative`; system SDL2 required.
- **Steam Deck:** mark the SteamOS AppImage executable and add it to Steam as a
  non-Steam game using a Gamepad layout. Select your ROM in the launcher.
  Use `--appimage-extract-and-run` if FUSE is unavailable. See
  [AppImage guide](../APPIMAGE.md) for state paths and build instructions.
- **Android:** install the APK (arm64-v8a and x86_64, Android 8+, upgrade code 12).
  The existing development signing certificate is retained.
- Contains no ROM, no save and no personal configuration.
- Standalone editor and example/Liga MX/World Cup packs are also provided.
- `SHA256SUMS.txt` covers every uploaded binary/package asset.

To use a cartridge pack, follow
[Cartridge packs](../MODDING.md#10a-cartridge-packs) in the modding guide: run
`python tools/convert_rom_hack.py --rom "Hack.sfc" --name "Hack"` (or `--ips`
for an existing patch) to build the pack, drop the generated
`mods/<slug>.json` and `mods/<slug>/` folder into `mods/`, and enable the pack
in the launcher's mods page. The converter ships in the release's mod-studio
tooling bundle as `tools/convert_rom_hack.py`; it needs Python and your own
verified retail cartridge.

## Validation and limits

The engine is a hybrid. Data-preserving hacks - squads, kits, palettes, text,
graphics - play as authored. Changes to code outside the interpreted paths
(boot, NMI and the deny-listed routines) are ignored, and hacks that relocate
data are read from their original addresses. Run the converter's `REPORT.md`
before installing anything; it names every changed region and what the runtime
will honor. Engine-rewriting hacks are not supported, and the converter cannot
make them so.

Saves written by this build - campaign, quick and the eight numbered manual
slots - are scoped to the cartridge image and refuse to load under a different
cartridge, in either direction. Legacy raw saves from older builds carry no
identity, so the game asks for the compatibility confirmation before loading
one.

With a cartridge pack active, a headered dump is normalized to the headerless
2 MB image before the pack is applied. That normalized image is what the pack
patches and what the saves are scoped to, so a headered and a headerless dump of
the same retail cartridge are the same base here.

Android in-process cartridge switching has not been run on a device. That
restart path is Android-only and not reachable from the desktop or headless
harness; a headless boot with a cartridge pack covers the applied image and a
clean exit, and the restart glue was reviewed line by line. Physical Steam Deck
Gaming Mode and full Cup/World Series playthroughs under a cartridge pack remain
pending as well. This is a beta.
