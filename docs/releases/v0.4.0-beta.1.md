# ISSD Native v0.4.0-beta.1

Beta prerelease for Windows x64 and Android 8.0+. The project remains below
1.0; netplay is not implemented.

## Changes

- Optional eight-direction enhanced running/dash animation, preserving original
  gameplay timing, sprite scale, palettes and depth. Walking and other actions
  retain their original animations.
- Fix modded team names and flags on verified competition screens and moving
  coin-toss panels, including Cup group/next-game and World Series slots.
- Extend coin-toss scenery for 16:10, 16:9 and 21:9 with varied whole fans,
  loaded-artwork checks, native vertical scrolling and one centered television.
- Widen the verified halftime statistics background while retaining the
  original centered card and sprite clipping.
- Remove Ball Outline, including saved legacy enables. Add optional Color Boost
  and adjustable CRT Strength with saved settings and preview support.
- Updated graphics, modding, supported-feature and acceptance documentation.

## Downloads

- Windows: extract `ISSDNative-v0.4.0-beta.1-windows-x64.zip` and run
  `ISSDNative.exe`; keep `SDL2.dll` and `aot_boot_deny.txt` beside it.
- Android: install `ISSDNative-v0.4.0-beta.1-android.apk` or use the Android ZIP.
  Version code 6; arm64-v8a and x86_64 are included. The existing development
  signing configuration is retained for beta sideloads and upgrade compatibility.
- Optional mod packs: `liga_mx_expansion.zip` and `world_cup_2026.zip`.
- `SHA256SUMS.txt` covers the downloadable packages.

Supply your own supported retail USA cartridge dump. No ROM, personal
configuration, saves or acceptance snapshots are included.

## Known limitations

Untouched complete Cup/World Series campaigns, completed draw-to-shootout flows,
physical four-controller matches and Android lifecycle/touch acceptance remain
pending. Optional AI balance and all stadium/mode combinations are not certified.
Widescreen scenery reuses original artwork; it is not newly drawn stadium art.
Binary downloads target Windows and Android; Linux is build-checked separately.

See the bundled supported-feature inventory and acceptance records for details.

## Validation

- Full project regression suite: **262 passed, 3 skipped, 7 subtests passed** in 1834.47 seconds.
- Windows x64, Linux and Android builds succeeded.
- Packaged Windows executable booted successfully from a clean extraction with isolated configuration and saves.
- Archive integrity, SHA-256 checksums, Windows x64 binaries and both Android ABIs were checked.
- Android signing certificate matches v0.3.0-beta.1; version code advances from 5 to 6.

These automated checks do not replace the pending physical-device and complete campaign acceptance listed above.
