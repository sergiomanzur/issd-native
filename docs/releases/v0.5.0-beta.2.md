# ISSD Native v0.5.0-beta.2

Beta prerelease for Windows x64, Linux x64 and Android 8.0+. Supply your own
supported retail USA cartridge dump. The packages include no ROM, personal
configuration or saves.

## New in this beta

- Add **Graphics > Camera**: Classic, **Tactical 80%** (25% more field coverage
  per axis), and **Tactical Wide 67%** (50% more). These are real expanded-world
  views with additional visible actors, preserving original projection/tracking
  and normal-size score, timer, radar, flags and labels. Camera selection persists.
- Support the tactical cameras in verified pitch gameplay and goal replays,
  including independently authored stadium geometry and local HD artwork.
- Record actual positions and animation descriptors for players omitted by the
  original narrow-view replay. Matching companion history restores those players
  and survives save/load, pause and rewind; stale unrecorded actors stay excluded.
- Keep black World Series/tournament cards centered in True widescreen, extending
  the background without stretching or reflecting the lettering into margins.
- Preserve enhanced-running animation when tactical sprite uploads occur.
- Correct tactical sprite overlap/order, layer windows and color effects, and
  clear auxiliary admission evidence on loading. Optimize unused subscreen sampling.
- Retain all v0.5.0-beta.1 audio, shootout, substitution, campaign, replay,
  expanded-stadium and Mod Studio fixes. Include the rebuilt editor and the
  MEADOW/HARBOR independent stadium example pack.

## Downloads and setup

- **Windows x64:** extract the Windows ZIP and run `ISSDNative.exe`. Keep
  `SDL2.dll` and `aot_boot_deny.txt` beside it. `ISSDModStudio.exe` is included.
- **Linux x64:** extract the tar.gz and run `./ISSDNative`. Keep the deny list
  beside it. Requires system SDL2 and compatible x86-64 Linux libraries; this
  build is tested on Ubuntu 24.04. Editor source is in `mod-studio-source/`.
- **Android:** install the standalone APK or extract the Android ZIP. Android
  version code is **8**, with arm64-v8a and x86_64. The existing beta development
  signing key is retained for compatible sideload upgrades.
- **Mod Studio:** a separate Windows ZIP includes the rebuilt editor and example
  pack. Platform bundles also include source for desktop Python/Pillow/Tcl/Tk.
- **Example pack:** platform bundles include it under `mods/`; enable
  **Independent stadium examples** in the mod list. Open
  `mods/independent_stadium_example.json` in Mod Studio. A standalone portable
  example ZIP, Liga MX and World Cup 2026 pack ZIPs are also available.
- `SHA256SUMS.txt` covers all eight binary/package assets.

## Validation and limits

Fresh complete regression passed **451 tests and 8 subtests**, with **5
documented skips** and no failures. Eight packaging/version-gate tests also
passed. Extracted Windows/Linux tactical-camera startup, cross-platform
image/state equality, editor workflows, checksums, and APK version/ABI/signing
checks passed.

Release validation is recorded in `docs/RELEASE_VALIDATION_0_5_0_BETA_2.md`;
rendering coverage and measured desktop costs are in
`docs/TACTICAL_CAMERA_1_0_VALIDATION.md`.

This remains a beta on the path to 1.0. Dedicated behind-goal penalty/shootout
views, management panels, campaign cards and unsupported scenes retain their
original camera. Earlier save formats remain readable, but old replay recordings
cannot recover player motion that was never captured. Independent stadiums remain
bounded by verified native geometry/resource constraints.

Physical Android gameplay/touch/lifecycle and a full human campaign playthrough
with camera switching remain release acceptance work for 1.0. Four-controller
physical acceptance and netplay remain outside this beta's certification.
No untested macOS or separate SteamOS binary is published.
