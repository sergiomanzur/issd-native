# ISSD Native v0.5.0-beta.4

Widescreen, animation and controller improvement beta for Windows x64, Linux x64 and Android 8.0+. Supply your own supported retail USA cartridge dump; ROMs, personal configuration and saves are not included.

## Changes

- **Fit Pixel Perfect Aspect Ratio:** New **Graphics → Aspect Ratio → Fit Pixel Perfect** option chooses a tested widescreen width at the largest whole-number scale fitting the viewport (e.g. 480x224 at 4x on 1080p; 426x224 at 3x on 1280x800).
- **Gameplay-Only Widescreen:** New **Graphics → Widescreen Menus → Off** keeps menus, title, coin toss and statistics centered at their original width while matches, replays and penalties remain wide.
- **Widescreen Environmental Polish:** Rain and snow fill wide margins without repeating HUD text; pitch boundary grounds fill margins cleanly without fence/billboard duplication; announcement bars retain original centered width.
- **Enhanced Walking and Running Animation:** Extended optional enhanced animation to ordinary walking in all eight directions, with interpolation cleanup and displayed animation phase alignment for offscreen actors.
- **Controller Slot Reclamation:** Immediate reclamation of detached controller slots before delayed SDL removal events, preserving independent attached controllers and reconnect held-input suppression; disambiguates identical controller models.
- **Licensing and Project Metadata:** Formal GNU General Public License v3.0 (`LICENSE`) and `.recomp.json` project metadata for recomp.board.
- **Retained Features:** Retains responsive touch controls, both tactical cameras, replay edge-player history, campaign card fixes, audio timing, shootout/substitution/campaign fixes, independent stadiums and Mod Studio.
- **Bundled Packages:** Windows x64, Linux x64 and Android packages include Mod Studio source, licenses and the MEADOW/HARBOR example stadium pack, alongside standalone editor, Liga MX and World Cup 2026 packs.

## Installation

- **Windows x64:** extract the ZIP and run `ISSDNative.exe`; keep `SDL2.dll` and `aot_boot_deny.txt` beside it. The frozen Mod Studio executable is included.
- **Linux x64:** extract the tar.gz and run `./ISSDNative`; requires system SDL2 and compatible x86-64 libraries (tested on Ubuntu 24.04). Bundles include editor Python/Pillow/Tcl/Tk source.
- **Android:** install the APK (arm64-v8a and x86_64, minimum Android 8), upgrade code **10**, retaining the previous beta's development signing certificate.
- `SHA256SUMS.txt` covers all packaged assets.
