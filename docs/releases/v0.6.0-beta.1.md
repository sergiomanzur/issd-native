# ISSD Native v0.6.0-beta.1

Retro broadcast launcher and match options beta for Windows x64, Linux x64,
Steam Deck (AppImage) and Android 8.0+. Supply your own supported retail USA
cartridge dump. ROMs, personal configuration and saves are not included.

## Changes

- Original retro football broadcast launcher with shared keyboard, mouse,
  controller and touch navigation; ROM selection, presentation, control presets,
  gameplay options and mods. Full remapping remains available in-game.
- Penalty timing-input correction in the existing optional bug-fix bundle:
  use the current taker's routed input while preserving goalkeeper controls.
- Separate default-off short goal kicks and final-attack protection.
- Team-strength summaries calculated from the applied roster and formation.
- Original, 1, 2, 3, 5, 7, 10, 15 and 20-minute regulation halves for Exhibition,
  Cup and World Series; scenario/training rules remain unchanged.
- ROM-free AppImage with writable XDG state and preservation of user mods.
- Retains widescreen, tactical cameras, touch controls, campaign recovery,
  replay fixes, independent stadiums and Mod Studio from earlier betas.

## Downloads and installation

- **Windows:** extract the Windows ZIP and run `ISSDNative.exe` with `SDL2.dll`
  and `aot_boot_deny.txt` alongside it. Includes the standalone Mod Studio editor.
- **Linux:** extract the Linux tar.gz and run `./ISSDNative`; system SDL2 required.
- **Steam Deck:** mark the SteamOS AppImage executable and add it to Steam as a
  non-Steam game using a Gamepad layout. Select your ROM in the launcher.
  Use `--appimage-extract-and-run` if FUSE is unavailable. See
  [AppImage guide](../APPIMAGE.md) for state paths and build instructions.
- **Android:** install the APK (arm64-v8a and x86_64, Android 8+, upgrade code 11).
  The existing development signing certificate is retained.
- Standalone editor and example/Liga MX/World Cup packs are also provided.
- `SHA256SUMS.txt` covers every uploaded binary/package asset.

## Validation and limits

Windows and Linux Release builds and both Android ABI release builds passed.
Feature and integration checks passed, including actual penalty opcodes and
real Exhibition duration initialization. The AppImage completed a 900-frame
no-FUSE headless run with a clean exit. See [release validation](../RELEASE_VALIDATION_0_6_0_BETA_1.md).
Physical Steam Deck Gaming Mode, Android picker/touch acceptance, four-controller
hardware and full Cup/World Series playthroughs remain pending. This is a beta.
