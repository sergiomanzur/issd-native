# ISSD Native v0.5.0-beta.1

Beta prerelease for Windows x64, Linux x64 and Android 8.0+. Supply your own
supported retail USA cartridge dump. No ROM, personal configuration or saves
are included.

## Changes

- Correct audio producer pacing, transfer handshakes and guest audio timing.
- Fix goal-replay edge players and stale animations in non-native aspect ratios;
  preserve saved replay animation history when loading snapshots.
- Repair expanded stadium selection and logical identity through original
  settings serialization, construction, replay and save/load.
- Add bounded independent stadium profiles: shortened pitches, native maps,
  character artwork, palettes and stadium-local HD replacements. Geometry
  enters save compatibility; changed or removed cosmetic resources refresh
  safely through the original transfer/fade flow.
- Improve Mod Studio with geometry and artwork tabs, drag editing, compiled
  previews and initial-camera view, image/HD import, undo/redo, unused-slot
  cloning, portable export and isolated asynchronous Test/Stop.
- Include MEADOW and HARBOR, two same-template stadiums with different lengths
  and newly authored simple artwork.
- Fix Cup shootout completion saves and validate substitutions, extra time,
  original campaign progression and Continue checkpoints. Record natural,
  uninterrupted Cup/World Series investigations separately from accelerated
  regression fixtures.
- Include the latest menu, stadium-background, HD rendering, match shortcut,
  persistence and documentation fixes since v0.4.0-beta.1.

## Downloads and setup

- **Windows x64:** extract the Windows ZIP and run `ISSDNative.exe`. Keep
  `SDL2.dll` and `aot_boot_deny.txt` beside it. `ISSDModStudio.exe` is included.
- **Linux x64:** extract the Linux archive and run `./ISSDNative`. Keep the deny
  list beside it. Requires system SDL2 and compatible x86-64 Linux libraries;
  this build is tested on Ubuntu 24.04. Editor source is in `mod-studio-source/`.
- **Android:** install the standalone APK or extract the Android ZIP. Version
  code advances to 7; arm64-v8a and x86_64 are included. The existing development
  signing configuration is retained for beta sideload upgrades.
- **Mod Studio:** a separate Windows ZIP includes the standalone editor and
  the example pack. Editor source is also included in the platform ZIPs/archive;
  running source requires desktop Python, Pillow and Tcl/Tk. See the bundled
  `docs/MOD_STUDIO_QUICKSTART.md` for exact paths and example-pack setup.
- **Example pack:** the standalone example ZIP can be opened in Mod Studio.
  Platform archives already contain its manifest and dependencies under `mods/`.
  Enable **Independent stadium examples** in the game's mod list. Open
  `mods/independent_stadium_example.json` in Mod Studio to edit it.
- Existing Liga MX and World Cup 2026 pack downloads remain included.
- `SHA256SUMS.txt` covers every uploaded binary/package asset.

## Validation and limits

Fresh full regression passed **430 tests and 8 subtests**, with 5 documented
skips; **8 new packaging tests** also passed separately. Clean extracted-package
startup, checksums, archive contents, Windows/Linux builds, Android
ABI/version/signing and editor workflow checks passed and are recorded in the
bundled `docs/RELEASE_VALIDATION_2026_10_10.md` report.

Both custom profiles completed uninterrupted natural matches with genuine goal
replays, halftime and fulltime. Moving and paused replay matrices passed at
native 8:7, 4:3, 16:10, 16:9 and 21:9 with native/HD artwork. Controlled weather,
original-code boundary and scenery checks are labeled separately from natural
playthroughs in the acceptance documentation.

This remains a beta. Independent geometry retains original scenery and template
widths, with shortened lengths in 32-unit steps and native resource budgets.
It does not provide arbitrary stadium architecture or a full decompilation.
Android physical-device gameplay/touch/lifecycle and physical four-controller
acceptance remain unverified. Netplay is not implemented. Optional AI balance
and every stadium/weather/mode combination are not certified.

See `docs/INDEPENDENT_STADIUM_ACCEPTANCE.md`, `docs/SUPPORTED_FEATURES.md` and
the bundled campaign, audio, shootout and substitution acceptance records.
