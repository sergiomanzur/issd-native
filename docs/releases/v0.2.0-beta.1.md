# ISSD Native v0.2.0-beta.1

This is a **beta prerelease**, with substantial improvements to local play,
campaign progress and optional AI tuning. The project is still working toward 1.0.

## Changes

- Up to four local SDL2 gamepads, stable player slots, SNES multitap support,
  disconnect notifications and automatic pause during live play.
- **Continue Campaign**, autosaves at safe Cup/World Series transitions,
  two recoverable backup generations, and checks against incompatible gameplay
  packs and tweak settings.
- Native password entry/export for all six original campaign password formats.
  Retail password exchange requires the original gameplay configuration.
- **Gameplay Tweaks** overlay page with independent, persistent, stackable
  goalkeeper and player AI switches. Goalkeeper positioning tracks angled shots;
  CPU off-ball targets use formation roles, current lineup attributes and condition.
  Both default off and apply live.
- Checked, transactional snapshots preserve CPU timing and multiplayer state;
  advancing save/load replay regressions pass.
- Updated guides, regression tests and release packaging.

## Downloads and installation

- **Windows:** extract `ISSDNative-v0.2.0-beta.1-windows-x64.zip` into a fresh
  folder and run `ISSDNative.exe`. Keep `SDL2.dll` and `aot_boot_deny.txt` beside
  it. Select your own supported USA cartridge dump on first launch.
- **Android 8.0+:** sideload `ISSDNative-v0.2.0-beta.1-android.apk`, or extract
  it from the Android ZIP. Both arm64-v8a and x86_64 are included. Version code
  4 allows updating the previous build with the same signing key. Back up your
  data before changing installations; uninstalling removes app-local saves.
- **Mods:** the existing `liga_mx_expansion.zip` and `world_cup_2026.zip` are
  optional downloads. Extract them into your mods folder, then select that
  folder in the overlay. They are not enabled automatically.
- **Checksums:** `SHA256SUMS.txt` covers all downloadable packages.

Open **Escape/F1** or gamepad **Guide/Home** / **Back+Start** for the overlay.
Connect up to four pads and select the original multiplayer player-count option
in Open Game. Human controls are preserved by the AI tweaks. Restore the same
mod/tweak combination when using Continue or loading a checked save.

No game ROM, personal configuration or saves are included. Supply your own
supported International Superstar Soccer Deluxe (USA) dump. Older release
packages do not contain these new features.

## Validation and known limitations

- Full project suite: **156 passed, 2 failed, 1 skipped, 7 subtests passed**.
  The remaining baseline failures are the appearance-nibble expectation in
  `test_mod_rom_patching` and kit-sharing validation in `test_shipped_packs_validate`.
- Final focused AI, menu, configuration, campaign, advancing replay, multiplayer
  and password verification: **34 passed, 1 skipped**.
- Windows, Linux and Android builds succeeded. The release packages target
  Windows and Android; no refreshed SteamOS binary is included.
- Four-controller hardware coverage, Android controls and physical-cartridge
  password comparison still need broader device testing. Initial AI tuning
  needs gameplay balance testing; it does not replace all cartridge AI.
- Wider aspect ratios remain experimental; original object culling can leave
  outer-edge actors frozen or incompletely animated. Use 4:3 for the baseline.
- Audio fidelity and complete end-to-end certification of every mode remain
  in progress. Android retains the existing debug signing configuration for
  sideload testing.

See the bundled README and gameplay, multiplayer, campaign and password guides
for controls and save compatibility details.
